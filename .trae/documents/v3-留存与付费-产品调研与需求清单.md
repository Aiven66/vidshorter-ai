## 一、执行摘要（结论先行）

Clipop AI 的差异化不在「再多一个 AI 功能」，而在**本地、无限、零按量费用**这一别人无法复制的结构性优势。因此本迭代的增长杠杆不是加功能，而是把「切换成本」做厚、把「本地无限」卖明白。

五条核心结论：

1. **留存的决定性动作是「48 小时内产出并导出第一条可直接发布的成片」**——行业实证「48h 内创建第二个项目」约带来 **3× 留存**。本迭代 P0 围绕首片速度与可直接发布性展开。
2. **付费的前提是「切换成本」，而切换成本的来源前三名是：品牌套件/模板、XML 工程回写专业软件、团队工作区+席位**——都是竞品（Submagic / Opus / Gling）验证过的卡口。本地产品做这三样天然占优（零上传、可离线）。
3. **本地产品必须反着卖**：竞品（Opus Clip / Submagic）按输入分钟或条数扣点、片段还会过期，Clipop 应明牌「**不限量、不扣点、不上传、不过期**」，把按量计费对手的痛点直接做成自己的卖点。
4. **定价要加「年付锚定 + 限量 Lifetime 买断」双轨**。Recut（$99–129 一次性）、Reelify for Mac（$59，官网明示 no credits/caps/uploads）证明本地/桌面产品用户强烈偏好买断；年付锚定可把收入提升 8%–45%、年付占比提升 25–35 个百分点。**反面教训**：Topaz Video AI 从买断转 $299/年、停付即锁新模型，引发口碑反弹，必须避免。
5. **发布环节只做「生成 + 导出 + 本地排期提醒」，绝不模拟登录直发**。2025-08 起抖音发布 API 收紧（企业主体、注册资本≥50 万、禁营销内容、90 天未调用回收），视频号无开放发布 API，YouTube 每日配额≈100 次上传；非官方接口风控率 **73% vs 合规 2.8%**，且会丧失流量扶持。

## 二、前提约束复核（违反即作废）

| 约束 | 落地要求 |
| --- | --- |
| **本地 AI 视频处理器**，核心是高光切片 | 所有新增能力走本地链路，可离线跑通 |
| **零第三方大模型 API** | LLM/VLM/ASR/TTS 一律本地（Qwen3-4B / CosyVoice3 / whisper.cpp 等） |
| **Apple Silicon 16GB 基线** | 不假设 CUDA / 大显存；只收 MPS / MLX / CoreML / ONNX 可跑的方案 |
| **安装包不能过大** | 小模型内置（<50MB 量级），大模型走按需下载（复用 `local-models:prepare` 范式 + 镜像源 + 断点续传） |
| **云端只做认证/支付/配置下发/可选付费重算力档** | 权益、账号、配置同步走 web 端；算力不上云 |
| **声音克隆** | 男声克隆必须输出男声；预览即播且播克隆音；中文读「你好，很高兴认识你，这是我的声音预览」 |
| **数字人** | 目标是 Hengen / TopView 级逼真，不接受照片式假数字人 |
| 包管理器 | 仅 pnpm |

## 三、三条调研线结论

### A. 竞品线：他们靠什么留住人、逼出付费

| 产品 | 免费额度与限制形态 | 留存钩子 | 付费卡口 | 定价形态 |
| --- | --- | --- | --- | --- |
| Opus Clip | 60 积分/月（按**输入分钟**扣）；水印；**片段 3 天过期** | 模板库、ClipAnything、发布排期 | 高阶 AI 额外耗点、去水印、超时长 | 订阅（月/年） |
| Submagic | 3 条/月；水印 | **Brand Kit**、团队批注、模板 | 去水印、条数、Brand Kit 高级项 | 订阅 |
| Gling | 按**媒体小时**计费 | **XML 导出到 Pr/FCP/Resolve** | 小时数、导出格式 | 订阅 |
| Kapwing | 水印、导出次数 | 团队工作区、模板 | 导出、分辨率 | 订阅 |
| Recut | —（桌面） | 本地运行、无持续成本 | **一次性买断 $99–129** | 买断 |
| Reelify AI for Mac | 官网明示 **no credits / caps / uploads** | 本地、无上限 | 一次性买断 $59 | 买断 |
| 剪映专业版 / CapCut | 导出须 Pro；1080p/60fps 上锁 | 模板生态、快捷键肌肉记忆 | 导出、分辨率、AI Ultra（¥199/月含 22100 点） | 订阅（$77→$179.99 涨价引差评） |
| 腾讯智影 / 度加 / 通义听悟 | 次数/时长限制 | 国内平台适配 | 次数、时长、导出 | 订阅 |

**三个结论**：
1. 切换成本来源前三 = **品牌套件/模板 > XML 回写专业软件 > 团队工作区+席位**——三者都是「用户投入了资产」的地方。
2. 零边际成本产品（本地）应把对手的按量计费直接反向卖：**无限量 + 品牌套件 + 团队席位 + XML 工程 + 资产库 + 批处理/排期**。
3. 买断范本 = Recut / Reelify；订阅教训 = Topaz 买断转年费锁新模型遭口碑反弹。

### B. 留存/付费方法论

- **Aha moment**：**48h 内产出并导出第一条可直接发布的成片**（「48h 内创建第二个项目」约 3× 留存）。行业锚点：剪映首次导出 6768 万；剪映 D7/D30 = **46.3% / 28.7%**（行业均值 34.1% / 19.2%）。
- **本地产品粘性来源**：本地工程/资产库（Obsidian file-over-app，500 万 MAU）、插件生态、模板预设、快捷键肌肉记忆、批处理管线。
- **Streak 有硬证据**：Duolingo 7 天连胜完成课程概率 **3.6×**、D7 **+14%**、「周末护身符」**+4%**。
- **年付锚定有效**：Mojo 收入 **+8%~45%**、年付占比 **+25~35pp**。
- **反模式（必须避免）**：不要限制本地算力次数/时长；不要强制联网校验；不要强行加水印（Unfold 差评潮）；不要把核心分辨率上锁（CapCut 1080p/60fps 差评潮）。

### C. 工作流痛点与本地化机会（含发布合规边界）

- **全流程痛点**：找素材慢 → 转写慢/不准 → 高光判断靠人 → 字幕对轴累 → 竖屏重构费时 → 导出/分发重复劳动 → 复审流转靠群。
- **MCN/工作室痛点**：批量出片、矩阵分发、平台查重、审核流转、资产中台（现价 **199–599 元/人/年**）。
- **本地独占优势（可直接讲）**：隐私/NDA 零外传、超大/超长素材、**无按量费用**、通宵挂机批量（实测 1 小时素材：本地转写 **8 分钟** vs 云端 **35 分钟**，M3 Pro）。
- **发布合规边界（硬约束）**：抖音「发布内容至抖音」2025-08 收紧（企业主体、注册资本≥50 万且满 1 年、禁营销内容、90 天未调用回收）；视频号无内容发布开放 API；YouTube Data API 10k 配额 / `videos.insert` 400 单位 ≈ 每天≤100 次；TikTok Content Posting API v2 可直发。**非官方风控 73% vs 合规 2.8%，且丧失流量扶持** → 桌面端只做「生成/导出 + 本地排期提醒」，不做模拟登录上传。
- **2025–2026 新信号**：多语言出海译配（原片不外传 + 省 API 费）、数字人口播、长视频改写系列、封面 A/B、爆款结构模仿、视频 SEO、评论区素材。

## 五、功能清单（P0 / P1 / P2，每项七列）

> 七列：用户价值 → **留存杠杆 / 付费杠杆**（至少命中一个）→ 技术方案（框架 + 代码/权重双 License）→ 硬件门槛 → 安装包体积影响 → 集成点 → 风险。

### P0 — 本迭代必须交付（直接拉动指标）

#### P0-1 品牌套件 Brand Kit（本地零上传）
- **用户价值**：一次配置品牌（Logo、字体、主色、字幕样式、片头片尾、水印位），此后所有成片自动统一，省去每条重复调样式。
- **留存杠杆 / 付费杠杆**：**留存**（沉淀品牌资产=切换成本，竞品切换成本来源第一名）+ **付费**（多品牌/多风格模板设为 Pro 权益）。
- **技术方案**：本地资产库（JSON + 文件目录）+ 现有 ffmpeg 渲染管线合成叠加；字体走系统字体优先，缺字时可从 web 端下发（字体文件 License 需逐个核对，见待核实清单）。
- **硬件门槛**：无（纯合成，无模型）。
- **安装包体积影响**：≈ 0（不打包字体，仅存配置；可选字体包按需下载）。
- **集成点**：桌面端渲染管线 `local-render`；web 端账号侧存品牌配置并下发；「选择桌面」页签新增品牌管理入口。
- **风险**：字体商用 License 是硬坑（须逐个核对）；品牌资产跨设备同步要走 web 端账号（本地优先，冲突需定策略）。

#### P0-2 本地工程文件（Project as File，资产沉淀）
- **用户价值**：每个项目落一个本地工程文件（`*.clipop`），可复用素材、断点续作、归档历史；换机器可带走。
- **留存杠杆 / 付费杠杆**：**留存**（历史资产 = 最高效切换成本，Obsidian file-over-app 500 万 MAU 为证）。
- **技术方案**：本地 SQLite（或 JSON + 素材引用路径）工程格式；素材以路径引用不复制；导出/导入工程包。
- **硬件门槛**：无（磁盘为主；超大素材需提示外置盘）。
- **安装包体积影响**：≈ 0（SQLite 走系统库或已在 Electron 依赖内）。
- **集成点**：桌面端 store 层（已有 YueCut `store` 范式可复用）；与 P0-1 品牌套件、P1-4 资产库打通。
- **风险**：素材路径失效（移动/删除源文件）需给出「重新定位」流程；工程格式需版本化以兼容升级。

#### P0-3 一键回写专业软件（FCPXML / EDL / AAF，Gling 式）
- **用户价值**：本地剪好的高光序列一键导出为工程文件，直接在 Pr / AE / DaVinci / 剪映里继续精修，不用从零重建时间线。
- **留存杠杆 / 付费杠杆**：**留存**（专业用户切走成本极高，竞品切换成本来源第二名）+ **付费**（多格式/AAF 设为 Pro 卡口）。
- **技术方案**：纯本地生成 **FCPXML / EDL**（文本格式，零依赖）；AAF 可选（复杂度高，标注待核实）。时间线数据来自现有高光 plan 结果。
- **硬件门槛**：无（纯文本生成）。
- **安装包体积影响**：≈ 0。
- **集成点**：桌面端高光导出流程新增「导出为工程」分支；粤剪批量导出的工程包格式复用。
- **风险**：各 NLE 对 FCPXML/EDL 版本兼容差异大，需逐软件实测（见待核实清单）；AAF 开源实现成熟度待核实。

#### P0-4 首片 5 分钟 Aha 引擎（48h 内出可直接发布成片）
- **用户价值**：新用户上传 1 条视频，5 分钟内拿到一条**可直接发**的竖屏成片（含字幕、品牌套件、封面），无需学任何设置。
- **留存杠杆 / 付费杠杆**：**留存**（命中 48h 出片 aha moment，约 3× 留存；对标剪映 D7 46.3%）。
- **技术方案**：默认高光预设 + 自动竖屏追焦（已有能力）+ stable-ts 逐词字幕（prd-desktop P0-2）+ P0-1 品牌套件默认样式；一键导出。
- **硬件门槛**：16GB 可跑（whisper small + 轻量渲染；首次模型下载需引导）。
- **安装包体积影响**：低（复用已有模型；仅新增预设配置）。
- **集成点**：桌面端首页流程；web 端下载引导 → 桌面端落地；与 v2「首次体验专项」协同不冲突。
- **风险**：首次模型下载慢会毁掉「5 分钟」体验 → 需进度可视 + 可跳过下载用 tiny 模型先出片。

#### P0-5 无限量本地批处理 + 通宵挂机队列（零按量）
- **用户价值**：一次投一批素材，通宵挂机自动出片；明牌「不限量、不扣点、不过期、不上传」。
- **留存杠杆 / 付费杠杆**：**留存**（批处理管线=肌肉记忆）+ **付费**（批量上限/并发数/矩阵模板设为 Pro）。
- **技术方案**：复用粤剪批量管线 + 任务队列 + 失败续跑 + 定时挂机；渲染并发按内存自适应。
- **硬件门槛**：16GB 可跑（需并发限流避免 OOM）；长时间任务需磁盘与发热管理。
- **安装包体积影响**：≈ 0。
- **集成点**：粤剪 `yuecut:*` IPC（batches / decision / engine:info）；`local-models:status` 复用。
- **风险**：并发过高触发内存压力；通宵任务需断点续跑与崩溃恢复，否则一次失败全批重来会伤留存。

#### P0-6 定价改造：年付锚定 + 限量 Lifetime 买断档 + 「本地无限」权益分层
- **用户价值**：想要一次买断的用户有明确选项；愿意订阅的用户获年付折扣；权益与本地能力对齐（不靠卡算力）。
- **留存杠杆 / 付费杠杆**：**付费**（年付锚定收入 +8%~45%、年付占比 +25~35pp；买断对标 Recut $99–129 / Reelify $59）。
- **技术方案**：web 端订阅/权益体系改造（subscriptions + credits 表）；桌面端只读权益并下发；买断档限量发售。
- **硬件门槛**：无（云端业务）。
- **安装包体积影响**：≈ 0。
- **集成点**：web 端定价页/支付；桌面端账号权益读取；避开 v2「付费墙放宽」的免费下载策略冲突（本项做**付费结构**，非免费额度）。
- **风险**：买断侵蚀订阅（限量+定高价缓解）；**禁止**做「停付即锁新模型」（Topaz 教训）；**禁止**卡本地导出/分辨率（CapCut 教训）。

### P1 — 下一迭代

#### P1-1 本地模板市场（可导入/导出模板包）
- **用户价值**：从模板一键套用出片风格；他人模板包可直接导入。
- **留存杠杆 / 付费杠杆**：**留存**（模板生态=切换成本）+ **付费**（精选/商用模板包收费）。
- **技术方案**：模板=配置包（样式+预设+品牌占位），存本地目录；导入导出走文件；无需服务器。
- **硬件门槛**：无。**体积**：≈ 0。**集成点**：P0-1 品牌套件 + 桌面端 store。
- **风险**：模板包含字体/音乐时的版权边界需明确（待核实）。

#### P1-2 连胜 Streak（周更连胜 + 周末护身符）
- **用户价值**：连续出片攒连胜，节假日自动护身不中断，形成习惯回路。
- **留存杠杆 / 付费杠杆**：**留存**（Duolingo 7 天连胜完成概率 3.6×、D7 +14%、护身符 +4%）。
- **技术方案**：纯本地计数（不是算力约束，仅习惯激励）+ 可选 web 端同步展示。
- **硬件门槛 / 体积**：无 / ≈0。**集成点**：桌面端本地状态 + web 端账号。
- **风险**：本地计数易被改；仅作激励不作权益门禁，避免变成「限制本地算力」的反模式。

#### P1-3 多语言译配（原片不外传，出海）
- **用户价值**：一条视频本地直接出多语言字幕+配音（含粤语）。
- **留存杠杆 / 付费杠杆**：**留存**（出海工作流刚需）+ **付费**（语言数/配音时长为 Pro 权益）。
- **技术方案**：本地翻译（Qwen3-4B）+ 本地 TTS 与克隆（CosyVoice3 含粤语，Apache-2.0 / GPT-SoVITS，MIT）；与 prd-desktop P0-1 声音克隆协同。
- **硬件门槛**：16GB 可跑（LLM 量化 + TTS 短时加载）。**体积**：大模型按需下载，包体 ≈0。
- **集成点**：桌面端译配模块；粤剪批量译配。
- **风险**：多语言音质一致性；**原片不外传**是卖点，需在 UI 明示。

#### P1-4 本地资产库（B-roll / 音效 / 贴纸 / 字幕样式片段级复用）
- **用户价值**：常用 B-roll、音效、贴纸、字幕样式沉淀入库，出片时片段级拖用。
- **留存杠杆 / 付费杠杆**：**留存**（库=切换成本）+ **付费**（官方素材包/容量为 Pro）。
- **技术方案**：本地素材索引库（复用 P0-2 存储）；缩略图本地生成。
- **硬件门槛 / 体积**：低（素材按需加入，包体不含素材）。
- **集成点**：P0-1 品牌套件、P0-2 工程文件、粤剪素材导入 `yuecut:material:*`。
- **风险**：素材版权来源须可控，避免用户导入侵权素材（免责+提示）。

#### P1-5 团队工作区 + 席位（本地工程共享）
- **用户价值**：MCN/工作室多人协同、工程共享、审核流转。
- **留存杠杆 / 付费杠杆**：**付费**（席位是竞品验证的核心卡口）+ **留存**（团队=最高切换成本）。
- **技术方案**：团队/席位走 web 端账号体系；工程共享走可选私有对象存储（仍需本地优先）；本地端只做权限读取与同步。
- **硬件门槛 / 体积**：无 / ≈0。**集成点**：web 端账号+支付；桌面端显示已登录团队。
- **风险**：涉云存储与合规；须保持「本地工程可独立跑通」，不可强依赖云端。

#### P1-6 封面 A/B + 视频 SEO 元数据（本地 LLM）
- **用户价值**：本地自动生成多版封面与标题/描述/标签，A/B 择优。
- **留存杠杆 / 付费杠杆**：**付费**（爆款封面/SEO 为 Pro）+ **留存**（提升发布效果→复访）。
- **技术方案**：本地 LLM（Qwen3-4B / Qwen2.5-VL，Apache-2.0）；封面合成走 ffmpeg。
- **硬件门槛**：16GB 可跑。**体积**：模型按需下载。
- **集成点**：桌面端结果页；P0-4 首片流程复用。
- **风险**：LLM 生成合规性（不得生成误导性标题）；多语言 SEO 质量。

#### P1-7 数字人逼真度升级（补足用户硬需求）
- **用户价值**：口型自然准确、手持产品自然讲解、面部无干扰光，逼近 Hengen/TopView 观感。
- **留存杠杆 / 付费杠杆**：**付费**（数字人档位/时长）+ **留存**（带货场景复访）。
- **技术方案**：现有 vendored MuseTalk + `real-human-engine` + `local-product-avatar` 提升；可选 LivePortrait（MIT）驱动；**红线**：Sonic/MatAnyone/LatentSync/EchoMimicV3/Hallo 等不可用（非商用或仅 CUDA/18GB+）。
- **硬件门槛**：16GB 可跑为底线（须量化与降分辨率策略）。
- **体积**：模型按需下载，包体 ≈0。
- **集成点**：`realhuman:*` IPC、数字人页面。
- **风险**：16GB 上逼真度与速度的平衡是最大不确定项（见待核实清单）。

### P2 — 规划项

#### P2-1 本地排期 + 合规导出包（不做模拟登录直发）
- **用户价值**：出片后按平台生成合规导出包与本地发布提醒日历。
- **留存杠杆 / 付费杠杆**：**留存**（发布闭环提高复访）。**付费**弱（可设高级排期为 Pro）。
- **技术方案**：本地日历/提醒 + 平台规格预设（分辨率/时长/封面）；**只导出不直发**。
- **硬件门槛 / 体积**：无 / ≈0。
- **集成点**：桌面端结果页；可选 TikTok Content Posting API v2（合规直发，仅该官方渠道）。
- **风险**：**必须避开**非官方模拟登录直发（风控 73% vs 合规 2.8%，且丧失流量扶持）；抖音/视频号 API 政策持续收紧。

#### P2-2 爆款结构模仿 + 评论区素材挖掘
- **用户价值**：分析爆款结构并在本地复用；从评论区提取选题素材。
- **留存杠杆 / 付费杠杆**：**付费**（Pro 洞察）+ **留存**（选题不枯竭）。
- **技术方案**：本地 LLM/VLM（Qwen3-4B / Qwen2.5-VL）。
- **硬件门槛**：16GB 可跑。**体积**：模型按需下载。
- **集成点**：桌面端分析模块。
- **风险**：抓取评论涉及平台 ToS（待核实）；结论质量依赖本地模型上限。

#### P2-3 可选云端付费重算力档（仅付费）
- **用户价值**：需要 4K 增强、超长视频语义级精修时，可选上云付费加速（本地链路仍独立可跑）。
- **留存杠杆 / 付费杠杆**：**付费**（高毛利增值档）。
- **技术方案**：云端跑仅 CUDA 的模型（LatentSync / SeedVR2 / HunyuanVideo-Avatar 等），按次/时长收费。
- **硬件门槛**：无（云端）。**体积**：≈0。
- **集成点**：web 端支付 + 桌面端可选上传。
- **风险**：与「零云端大模型」定位并存，须严格限定为**可选**且默认本地，避免定位漂移；数据合规需明示。

## 六、里程碑顺序（建议）

1. **M1（本迭代前半）**：P0-1 品牌套件 → P0-2 本地工程文件 → P0-4 首片 5 分钟 Aha 引擎。打通「资产沉淀 + 首片出片」闭环。
2. **M2（本迭代后半）**：P0-3 FCPXML/EDL 回写 → P0-5 无限量批处理队列 → P0-6 定价改造（年付 + 限量买断）。完成「切换成本 + 付费结构」闭环。
3. **M3（下一迭代）**：P1-1 模板市场 → P1-2 Streak → P1-3 多语言译配 → P1-4 资产库 → P1-5 团队席位 → P1-6 封面/SEO → P1-7 数字人升级。
4. **M4（规划）**：P2 三项。

依赖关系：P0-1/P0-2 是 P1-1/P1-4/P1-5 的前置；P0-4 依赖 prd-desktop 的字幕/高光能力；P0-6 依赖 web 端支付改造。

## 七、待核实清单（集成前必须实测）

1. **字体商用 License**：Brand Kit 内置/分发字体须逐个核对（含免费商用白名单与嵌入授权），红线项禁止打包。
2. **FCPXML / EDL / AAF 兼容性**：在 Pr、AE、DaVinci、剪映实测导入是否丢轨道/丢标记；AAF 开源实现成熟度待核实。
3. **16GB 数字人逼真度与速度**：MuseTalk 升级 + LivePortrait 在 16GB 上的帧率/口型质量实测（是否达 TopView 观感）。
4. **本地 LLM 质量天花板**：Qwen3-4B 量化版在译配/SEO/选题上的实际可用度（vs 需要的模型档位）。
5. **CosyVoice3 粤语克隆音质**：男声克隆输出男声、预览即播、粤语自然度实测（对应硬约束）。
6. **批处理并发上限**：16GB 下同时渲染/转写的安全并发数，OOM 边界与失败续跑机制。
7. **工程文件跨版本兼容**：`*.clipop` 格式版本化与升级迁移策略。
8. **平台发布 API 政策**：TikTok Content Posting API v2 直发合规性；抖音/视频号政策的当期口径（每季度复核）。
9. **素材版权边界**：模板包含音乐/字体、用户导入 B-roll 的版权提示与免责方案。
10. **买断档定价与限量**：Lifetime 价格与限量数、对订阅收入的侵蚀测算（对标 Recut $99–129 / Reelify $59）。
11. **模型镜像与断点续传**：按需下载在国内网络的可用性（复用 `local-models:prepare` 镜像源是否覆盖新增模型）。
12. **Obsidian 式本地库性能**：资产库/工程库在数万文件量级下的索引与检索性能。
