# Clipop AI v4 下个迭代产品调研与需求清单（付费转化 × 留存专项）

> 依据：飞书文档《海外 AI+SaaS 付费破局：Clipop 转化诊断、已验证付费机制与五个值得做的方向》（2026-10-22）
> 复核方式：文档结论 + 当前仓库代码逐项核对（`src/`、`apps/macos-agent/`）
> 目标函数：**留存率 + 付费率**，不是功能数量
> 结论边界：本文只写调研与需求，不改产品代码；文中“已有/部分/缺失”均以 2026-10-22 的代码为准，上线后需复测。

## 一、执行摘要（结论先行）

1. **下个版本不新增产品线，先修现有漏斗。** 付费率为零的主因不是定价，而是三处同时断裂：支付主路径不可用、免费额度没有断崖、交付不出可发布成品。
2. **P0 只做 5 件事，全部是站内改动：**
   - 支付主路径收敛到可用通道，删除死通道与虚假支付宣称；
   - 免费首条给 9:16 竖版成片（720p + 水印），第 2 条起锁；
   - 单条任务 15 分钟超时对账产品化：自动退积分 + 一键重试 + 不依赖用户轮询；
   - 免费额度改为「注册赠 180 积分 + 每日 60 + 每月 600 封顶」；
   - 定价页补「7 天首订退款 · 失败自动退积分 · 随时取消」三承诺。
3. **P1 补商业基础设施：** 年付 SKU、三档对比表、积分包重构、免注册 demo、注册减负、真实社会证明、Dashboard 口径。
4. **P2 才谈新方向：** 长内容转图文（现金流）与代运营客户交付工作台（长期），两者都要过明确 kill line；API、白标、企业本地化、数字人、消费级写真本轮不做。
5. **与既有文档的关系：** 超时退费、link_only 自动兑现、免费下载额度、月度积分重构已在历史文档/代码中落地，本文不重复；本文新增的是**支付断路、首条竖版、额度结构、信任承诺、商业基础设施**。

## 二、前提与现状复核

### 2.1 不可动摇的前提

- Web 端与桌面端共用同一套账号、订阅与积分口径；云端只承担认证、支付、配置下发与可选重算力，桌面端本地链路必须能独立跑通。
- 不新增第三方大模型依赖；内容类能力优先复用现有 transcript / 本地模型（Qwen3-4B, Apache-2.0），新增模型必须同时核对代码 License 与权重 License。
- 任何付费墙改动不得破坏现有功能；所有门控必须服务端裁定，不能信任客户端传入的 plan。
- 包管理器仅 pnpm；不新增依赖优先。

## 三、诊断结论（文档 + 代码复核）

### 3.1 三处断裂

1. **支付断路（极高影响）：** 默认 Creem 不可用；PayPal 只在文案里存在。走到定价页与订阅弹窗的人，是付费意愿最强的一批，却全部撞在报错页。
2. **免费额度无断崖（高影响）：** 60 credits/天 = 30 条/月，约为 Opus Clip 免费额度的 30 倍；付费只买到 3.3 倍产能。按天重置意味着重度用户也永远不撞墙。
3. **交付不出成品（高影响）：** 免费用户拿到 720p + 水印 + 横版；竖版锁在 Starter+；批量锁 Starter+；大量任务停在 Pending。用户已经投入时间，却在最后一步发现拿不到能发布的东西。

### 3.2 已验证的付费机制（12 个海外案例）

- 没有一个案例把付费点设在“能不能生成”，全部设在**导出、时长、商用许可、额度耗尽**四类交付环节。
- 最值得直接搬的四条：
  - **导出时间窗**（Opus Clip：成品 3 天后不可导出）；
  - **单条素材时长上限**（Submagic：2/5/30 分钟分档）；
  - **日额度 + 月封顶**（Lovable：5/天、30/月）；
  - **一次性小额试用**（Klap：1 条终身；Gamma：积分不刷新）。
- 不适合照搬：Cal AI 的“周价 + 自动续费”曾导致下架，不抄。

### 3.3 定价与人群错位

- 同赛道入口价已收敛在 **$14–$19**（Klap 年付 $14、Vizard 年付 $14.5、Opus $15、Submagic $19），Clipop $9.9 既浪费升级空间，也不像专业工具。
- 免费 30 条/月 vs 竞品 1–60 条/月；付费起点最低但无年付、无对比表、无退款承诺 → 被读成“便宜但弱”。
- 人群错配：一套 60/日额度同时服务轻度、重度与中文长视频用户，三簇人都不满足。

#### P0 验收标准

- 支付：定价页 → Waffo checkout → 支付成功 → 积分/订阅到账，全链路至少 1 次真实 $0.01 测试通过；Creem 创建失败率归零（因为不再作为主路径）。
- 首条竖版：新账号第 1 条可导出 9:16（720p + 水印 + 字幕）；第 2 条返回 403 且 CTA 正确；额度流水恰好 1 条。
- 超时：人为制造一条 15 分钟无进展任务，cron 落 failed、退 60 积分、前端出现一键重试。
- 额度：新账号首次登录余额 180；当日用完后次日恢复 60；月累计 600 后不再恢复。
- 信任：定价页三承诺可见；Terms §13 与定价页一致；`support@clipop.ai` 可达。

| 阶段 | 动作 | 判断线 |

## 七、待核实清单（上线前必须实测）

1. **Waffo 生产凭证与币种**：是否支持 USD/CNY、年付 SKU、退款 API、订阅周期字段。

8. **真实案例授权**：P1-6 的 3 条案例是否拿到原作者授权与可公开的联系方式。

## 八、本轮明确不做

| 不做项 | 原因 |
|--------|------|
| 第四个产品 / 新独立站 | 6 个月内不开；新方向拉来的人只会走进同一个坏漏斗 |
| 高光切片 API / 白标嵌入（方向二） | 需 6 个月签 3 家付费集成方，回款慢，当前团队与法务成本不匹配 |
| 长视频多语种企业本地化（方向五） | 企业要声音授权书、DPA、发票、SSO；项目制回款 30–60 天，现金流垫不住 |
| 本地优先企业桌面版（方向四） | “因隐私付费”零公开证据；企业采购 2–6 个月且要 SOC2/DPA |
| AI 数字人 / 口播视频 | 版权与资产生意，不是工具生意；页脚已有入口，本轮不再加码 |
| 消费级 AI 写真 / 头像 | 获客被 SEO 榜单与买量锁死，0 预算进不去 |
| 中文低价区独立产品 | 人民币收款未打通，给付不出钱的池子再加产品只会摊薄主线 |
| 恢复 `SHOW_MARKETING_SECTIONS=true` 的整页营销区块 | 会重新拉长首屏、干扰工作台；只露出 P1-4 的 demo，不恢复整页营销 |
